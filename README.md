# 안드라스 온라인 설치 파일

[playandras.com](https://playandras.com) 의 **게임 다운로드** 단추가 이 저장소의 최신 배포를 가리킵니다.
이 저장소에는 설치 파일만 올립니다(게임 소스는 비공개).

## 설치

1. [최신 배포](https://github.com/loui-kim/andras-releases/releases/latest)에서 `AndrasSetup-버전.exe` 를 받습니다.
2. 실행하면 Windows 가 **"Windows의 PC 보호"** 창을 띄울 수 있습니다.
   아직 코드 서명 전이라 그렇습니다. **추가 정보 → 실행** 을 누르세요.
3. 설치 폴더(기본: 내 사용자 폴더)를 확인하고 **설치**. 관리자 권한은 필요 없습니다.
4. 바탕화면이나 시작 메뉴의 **안드라스 온라인** 으로 실행합니다.

## 제거

Windows **설정 → 앱 → 설치된 앱** 에서 "안드라스 온라인"을 제거하거나, 설치 폴더의 `uninstall.exe` 를 실행합니다.

## 요구 사항

- Windows 10 / 11 (64비트)
- 인터넷 연결(게임 서버 접속)
